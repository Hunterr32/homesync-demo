# HomeSync: iPhone app demo

**Try it:** https://hunterr32.github.io/homesync-demo/

This is an interactive preview of how the HomeSync iPhone app looks and works.

- It is **not connected to Firebase** or any account, server or database. It runs entirely in your browser.
- **Nothing is saved.** Refresh the page and it starts over.
- Every person and home in it is made up.

More about the project: [HomeSync showcase](https://github.com/Hunterr32/homesync-showcase)
